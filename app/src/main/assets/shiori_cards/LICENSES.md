# Licences — Shiori Cards placeholder pack

Every image in this pack was generated procedurally from scratch by
`cards/placeholder-gen/generate.swift` (CoreGraphics / CoreText / ImageIO + zlib). No stock
textures, no third-party artwork, no AI-generated images.

## Fonts

**No font is bundled.** No OFL display font was available offline when this placeholder was made,
so `manifest.json` has `"fonts": {}` and the apps fall back to the platform system font for the
card name. The wordmark and badge letters were rendered with macOS system fonts (Avenir Next) into
the PNGs only; no font file is redistributed.

The real pack replaces this folder and must list its bundled OFL font here.
